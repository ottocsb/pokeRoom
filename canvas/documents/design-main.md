# 德州扑克 · 主设计文档

## 玩家幻想
坐在一张属于自己的牌桌前，与 4 位风格各异的 AI 对手进行无限注德州扑克；随时可以把牌桌"换装"成不同主题，并且始终清楚自己手里现在拼成了什么牌型。

## 核心循环
1. 盲注（10/20）→ 发两张底牌
2. 翻牌前 / 翻牌 / 转牌 / 河牌 四轮下注：弃牌、过牌、跟注、加注、全下
3. 摊牌比牌，赢家收池（支持边池与平分）
4. 庄位轮转，进入下一手；玩家筹码归零 → 游戏结束 → 重新开始；AI 筹码耗尽则离桌

## 核心特色
- **实时牌型提示**：玩家底牌下方常驻显示"当前牌型"（高牌 → 皇家同花顺），并高亮组成最佳五张的牌；可展开牌型阶梯查看全部牌型与当前所处位置。摊牌时每位玩家展示其牌型。
- **主题牌桌**：经典绿呢 / 午夜霓虹 / 皇家酒红 / 东方墨韵 四套主题，切换桌布纹理、桌沿、背景、筹码与牌背配色、字体，选择保存在 localStorage。

## 操作
- 指针/触屏：底部操作栏按钮；加注使用滑杆与快捷额度（½池、池、全下）
- 键盘：F 弃牌、C 过牌/跟注、R 加注、A 全下、空格/Enter 下一手

## AI
基于手牌强度（翻牌前起手牌评分，翻牌后蒙特卡洛胜率估计）+ 底池赔率 + 个性（紧/松、凶/弱）+ 少量随机诈唬。

## 技术
Vite + TypeScript，DOM/CSS 渲染（牌面用 CSS 绘制），响应式布局适配宽屏与竖屏手机。
测试桥：`globalThis.__OHMYGAME_PLAYTEST__`（snapshot / reset / setSeed）。

## 资产
- 视觉稿与四套桌布纹理的生成节点已保存在画布上；当前环境未配置图像生成，因此实现中桌布纹理、桌沿、徽记、牌面与牌背全部用 CSS 渐变 + 内联 SVG 程序化绘制（每套主题一组 CSS 变量）。日后生成图片后可替换为 `.felt` 背景。

## 实现备注
- 源码：`src/game.ts`（规则引擎、边池）、`src/evaluator.ts`（任意 2–7 张牌的牌型判定 + 听牌检测）、`src/ai.ts`（蒙特卡洛胜率 AI）、`src/main.ts`（渲染/输入）、`src/style.css`（四套主题变量）。
- 牌型提示：手牌下方徽章显示牌型名称、起手牌描述（翻前）或听牌（同花听牌 / 两头顺 / 卡顺），10 格进度条表示牌型等级；构成牌型的牌在手牌与公共牌上金色描边，其余公共牌变暗；牌型升级时徽章闪烁并播放音效。
- 依赖安装使用 bun（`bun.lock`）；esbuild 固定为 0.28.2 以匹配预览环境。

## 联机模式（账号 / 房间 / 入座）
- **流程**：登录页（账号 + 密码，登录 / 注册两个页签；也可直接"单机练习"）→ 主页，只有三项功能：**创建房间** / **输入邀请码加入房间** / **单机练习**。没有公共房间列表，所有联机房间都由玩家创建、凭邀请码（或邀请链接 `?room=CODE`）进入 → 进入房间先旁观 → 点击牌桌上的「入座」空位坐下（按房间买入额）。
- **创建房间**：房型 6 人桌 / 9 人桌；盲注级别 1/2、5/10、10/20、25/50、50/100、100/200；买入 50 / 100 / 200 BB。创建后自动弹出邀请码与链接；房间无人 30 分钟后解散。
- **开局**：房间内 ≥2 人在座（且至少 1 名真人）自动发牌；每手结束 5 秒后自动下一手。人不够可点顶栏「+电脑」在空座补一名 AI（「−电脑」本手后移除）；只剩电脑时自动清空。
- **行动计时**：真人每次行动 25 秒，座位铭牌下有倒计时条、自己的状态栏显示剩余秒数；超时自动过牌（需跟注时弃牌）。
- **中途加入 / 离开**：手牌进行中入座 → "下一手加入"；手牌中起身 → "离座中"，轮到时自动弃牌、本手结束后让出座位。筹码输光自动起身，可重新入座买入。
- **断线**：断线显示"离线"，轮到时 1.2 秒后自动行动；60 秒内重连（或刷新页面）自动回到原座位；同一账号在别处登录会把旧连接踢下线。
- **信息安全**：服务器权威结算，只给每个客户端发送其本人底牌，其他人的底牌在摊牌前只以牌背出现。
- **顶栏**（联机房间内）：邀请 / 起身 / +电脑 / −电脑 / 离开（回主页），其余与单机相同；单机模式下"牌桌"按钮打开单机牌桌设置（可返回主页）。

## 联机技术
- `server/poker-server.ts`：WebSocket 服务（`ws`），复用 `src/game.ts` 规则引擎（`solo=false`，按座位号的 `players` 数组，空座为 `empty` 占位），账号存 `server-data/users.json`（scrypt 加盐哈希 + 登录令牌），房间状态在内存中。
- `server/vite-plugin.ts`：把 `/poker-ws` 挂到 Vite dev/preview 服务器上，预览即可联机。
- `server/standalone.ts` + `npm run server`：独立部署（同端口提供 dist 静态文件 + WebSocket，`PORT` 默认 8787）。纯静态发布没有服务器时，登录页显示"无法连接联机服务器"，单机练习仍可用；也可用 `VITE_POKER_SERVER=wss://…` 构建指向外部服务器。
- 客户端：`src/remote.ts`（连接、自动重连、`RemoteTable` 只读镜像，与 `Game` 共享渲染接口 `TableLike`），`src/protocol.ts`（消息类型）。
